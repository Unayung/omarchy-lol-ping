A 3x3 sprite sheet of nine game HUD ping icons for a fantasy MOBA-style desktop toy, on a fully transparent background.

Layout: an invisible 3x3 grid of equal square cells. Exactly one icon per cell, centered in its cell, each icon filling about 70% of its cell, generous empty margin around every icon so nothing touches a cell edge. No grid lines, no cell borders, no background panels, no labels, no text or letters anywhere.

Shared style for all nine, so they read as one set: glossy, slightly 3D emblem icons seen straight on; thick dark navy outline; thin bright inner highlight along the top edges; a bevelled antique-gold rim; one vivid saturated main colour per icon with a soft top-to-bottom gradient; crisp clean shapes that stay legible at 48 pixels; no drop shadow or glow outside the icon itself.
